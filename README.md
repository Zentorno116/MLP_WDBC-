## Описание проекта
Реализация полносвязного многослойного персептрона с нуля на языке Python с использованием библиотеки NumPy (без использования Keras, PyTorch, scikit-learn). Модель решает задачу бинарной классификации опухолей молочной железы (набор данных Wisconsin Diagnostic Breast Cancer, WDBC) на доброкачественные (B) и злокачественные (M).

## Структура проекта
* `model.py` — архитектура MLP, прямой и обратный проход (Backpropagation), функции активации, сериализация модели.
* `data_split.py` — разделение данных на обучающую (`train.csv`) и валидационную (`val.csv`) выборки со стратификацией и сидом `seed=321`.
* `train.py` — обучение нейросети, расчет потерь на каждой эпохе, сохранение весов в `saved_model.npy` и кривых обучения в `learning_curves.png`.
* `evaluate.py` — загрузка весов, нормализация данных, расчет Binary Cross-Entropy и метрик качества (Accuracy, Precision, Recall, F1, Confusion Matrix).
* `report.pdf` / `report.tex` — подробный отчет со всеми математическими выкладками и листингами программ.

## Инструкция по запуску

### 1. Разделение данных
```bash
python data_split.py
```

### 2. Обучение модели
```bash
python train.py --layer 24 24 --epochs 84 --batch_size 8 --learning_rate 0.0314
```

### 3. Оценка качества и прогнозирование
```bash
python evaluate.py val.csv
```
